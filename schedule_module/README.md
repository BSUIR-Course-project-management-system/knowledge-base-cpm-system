# Shedule module


## Описание модуля:

Пользователь вводит ФИО проверяющего и проект в строку поиска, далее следует запрос к модулю **table_api**, который возвращает список занятых дат у введенного проверяющего, после чего **schedule_module** составляет список потенциальных дат для проведения опроцентовок, проверяя что они не попадают на занятые дни у проверяющего и не являются выходным или праздником. Затем среди этих дат выбираются 3 даты максимально равномерно распределенные по семестру для равномерного отслеживания прогресса проекта. Затем **schedule_module** отдает график опроцентовок **table_api** для внесения изменений в Google-таблицу.

## Технологии и библиотеки:

* holidays
