# Recommendation Module

Модуль рекомендаций дополняет результаты поиска тем понятными объяснениями. Он не
строит поиск с нуля, а использует `search_module`, после чего показывает, почему
конкретная тема попала в выдачу.

## Что делает модуль

- запускает поиск тем через `ThemeFinderManager`;
- фильтрует результаты по максимальной дистанции поиска;
- пересчитывает `cosine similarity` между запросом и найденными темами;
- выделяет совпадающие ключевые слова;
- добавляет описание темы, куратора и проверяющего;
- пишет отчёты в логи.

## Основные файлы

- `src/recommendation_module.py` — основной класс `RecommendationModule`;
- `src/main.py` — консольный запуск и демонстрация работы;
- `src/settings.py` — пути к логам и файлу с описаниями тем;
- `logs/search_ranking.log` — лог ранжирования и объяснений;
- `logs/topic_descriptions.log` — лог подробных описаний тем.

## Запуск

```bash
python3 -m interface.main
recommend
```

После запуска нужно ввести запрос. Дополнительно можно ограничить поиск свободными
темами, куратором или проверяющим.

## Сценарий работы

1. `ThemeFinderManager` загружает темы и готовит векторную коллекцию.
2. Пользователь вводит запрос.
3. `search_module` ищет близкие темы по эмбеддингам.
4. `RecommendationModule` формирует объяснение для каждой найденной темы.
5. Пользователь получает список тем с описаниями, а детали сохраняются в логах.

## Результат рекомендации

Каждая рекомендация содержит:

- `document` — название темы;
- `distance` — дистанция из поискового модуля;
- `similarity` — косинусное сходство запроса и темы;
- `similarity_label` — текстовая оценка близости;
- `search_explanation` — объяснение выбора темы;
- `topic_description_text` — описание темы, куратор и проверяющий.
